RECOMMENDED APPROACH: Add as a subdirectory

================================================================================
5-MINUTE SETUP
================================================================================

1. Navigate to your existing repo
   cd /path/to/your/existing/repository

2. Create unihealth-360 folder
   mkdir unihealth-360

3. Copy all UniHealth files into this folder
   cp -r /path/to/unihealth-provider unihealth-360/
   cp -r /path/to/unihealth-patient360 unihealth-360/
   cp -r /path/to/unihealth-shared unihealth-360/
   cp /path/to/docker-compose.yml unihealth-360/
   cp /path/to/.env.example unihealth-360/
   cp /path/to/*.md unihealth-360/
   cp /path/to/*.txt unihealth-360/

4. Create .gitignore in unihealth-360/ folder
   (See ADD_TO_EXISTING_REPO.md for full .gitignore content)

5. Add to git
   git add unihealth-360/

6. Commit
   git commit -m "feat: Add UniHealth 360 mobile apps as subdirectory"

7. Push
   git push origin main

Done! 🎉

================================================================================
ACCESSING UNIHEALTH FROM YOUR REPO
================================================================================

From repo root:

# Development
cd unihealth-360/
docker compose up -d
cd unihealth-provider && npx expo start

# Or directly:
cd unihealth-360/unihealth-provider
npm install
npx expo start

# Build for Play Store:
cd unihealth-360/unihealth-provider
eas build --platform android --profile production
