COMMON FIRST-RUN ISSUES & FIXES
================================================================================

Issue: "npm: command not found"
Fix:   Install Node.js from https://nodejs.org
       Restart terminal after installation

Issue: Port 8081 in use
Fix:   Close other Metro bundlers
       Or: lsof -ti:8081 | xargs kill -9 (macOS/Linux)

Issue: Emulator not showing
Fix:   Open Android Studio → AVD Manager → Launch emulator
       OR
       Install Expo Go app on physical device

Issue: App crashes on startup
Fix:   Check console for errors
       Run: npm install --legacy-peer-deps
       Try again

Issue: Can't connect to device
Fix:   Make sure USB debugging enabled (physical device)
       Or: Try Expo tunnel mode: npx expo start --tunnel

Issue: "google-services.json not found"
Fix:   File must be in app root directory, not in assets/
       Path: unihealth-provider/google-services.json

Issue: Debugging port blocked
Fix:   Check firewall settings
       Allow VS Code through firewall

Fix 99%+ of issues: Restart everything
  • Close debugger (Shift+F5)
  • Close emulator
  • Close all terminals
  • Reopen VS Code
  • Try again
