BLOCKER #2: Missing Firebase Configuration
────────────────────────────────────────────

WHAT'S MISSING:
  • unihealth-provider/google-services.json
  • unihealth-patient360/google-services.json

HOW TO FIX:
  1. Go to console.firebase.google.com
  2. Click "Create Project" → Name: "UniHealth 360"
  3. Add Android app → Package: ke.unihealth360.provider
  4. Download google-services.json
  5. Save to: unihealth-provider/google-services.json
  6. Repeat for patient app (ke.unihealth360.patient)

TIME TO FIX: 15-30 minutes
BLOCKER SEVERITY: 🔴 CRITICAL (Build fails without this)

────────────────────────────────────────────────────────────────────────────

BLOCKER #3: EAS Project IDs Are Placeholders
──────────────────────────────────────────────

CURRENT STATE IN eas.json:
  "projectId": "REPLACE_WITH_EAS_PROJECT_ID"  ← WRONG

REQUIRED STATE:
  "projectId": "abc123def456@exposed"  ← REAL ID

HOW TO FIX:
  1. Go to expo.dev and sign up (free)
  2. For each app:
     cd unihealth-provider
     eas init
     → Select GitHub account
     → Selects repo
     → Creates project and updates eas.json ✓
  
  3. Configure credentials:
     eas credentials
     → Select Android
     → Choose "Let EAS manage signing"
  
  4. Verify: eas.json now has real project ID (not placeholder)

TIME TO FIX: 1-2 hours
BLOCKER SEVERITY: 🔴 CRITICAL (Build fails without this)

WHAT'S MISSING:

  • play-store/feature-graphic.png (1024×500)

HOW TO FIX:

SCREENSHOTS:
  1. Start emulator: npx expo start → press 'a'

  5. Need: 4-8 screenshots

FEATURE GRAPHIC:
  1. Use Canva.com (search "feature graphic 1024x500")
  2. Or hire designer
  3. Save as: play-store/feature-graphic.png

PRIVACY POLICY:
  1. Use template from privacypolicygenerator.info
  2. Or hire legal to write one
  3. Save as: play-store/privacy-policy.html
