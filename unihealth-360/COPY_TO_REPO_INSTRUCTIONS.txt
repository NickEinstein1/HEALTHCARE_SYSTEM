TWO-OPTION SETUP
================================================================================

OPTION 1: Use the Automated Script (Recommended)
==================================================

macOS / Linux:
  bash add-unihealth-to-repo.sh ~/Documents/GitHub/HEALTHCARE_SYSTEM

Windows (PowerShell or Command Prompt):
  add-unihealth-to-repo.bat C:\Users\YourName\Documents\GitHub\HEALTHCARE_SYSTEM

Or if running from Command Prompt:
  add-unihealth-to-repo.bat "C:\Users\YourName\Documents\GitHub\HEALTHCARE_SYSTEM"

The script will:
  1. Create unihealth-360/ folder in your repo
  2. Copy all files (apps, configs, documentation)
  3. Create .gitignore
  4. Stage all files for git
  5. Create a commit
  6. Push to GitHub

Result: Your repo will have unihealth-360/ as a subdirectory, ready to use.

OPTION 2: Manual Setup (if script doesn't work)
================================================

1. Create directory in your repo:
   mkdir ~/Documents/GitHub/HEALTHCARE_SYSTEM/unihealth-360

2. Copy files (from this session):
   macOS/Linux:
     cp -r unihealth-provider ~/Documents/GitHub/HEALTHCARE_SYSTEM/unihealth-360/
     cp -r unihealth-patient360 ~/Documents/GitHub/HEALTHCARE_SYSTEM/unihealth-360/
     cp -r unihealth-shared ~/Documents/GitHub/HEALTHCARE_SYSTEM/unihealth-360/
     cp *.md *.txt docker-compose.yml .env.example ~/Documents/GitHub/HEALTHCARE_SYSTEM/unihealth-360/

   Windows (PowerShell):
     Copy-Item -Path "unihealth-provider" -Destination "C:\Users\YourName\Documents\GitHub\HEALTHCARE_SYSTEM\unihealth-360" -Recurse
     Copy-Item -Path "unihealth-patient360" -Destination "C:\Users\YourName\Documents\GitHub\HEALTHCARE_SYSTEM\unihealth-360" -Recurse
     Copy-Item -Path "unihealth-shared" -Destination "C:\Users\YourName\Documents\GitHub\HEALTHCARE_SYSTEM\unihealth-360" -Recurse
     Copy-Item -Path "*.md","*.txt","docker-compose.yml",".env.example" -Destination "C:\Users\YourName\Documents\GitHub\HEALTHCARE_SYSTEM\unihealth-360"

3. Add to git:
   cd ~/Documents/GitHub/HEALTHCARE_SYSTEM
   git add unihealth-360/
   git commit -m "feat: Add UniHealth 360 mobile apps"
   git push origin main

NEXT STEPS (After copying to repo)
================================================================================

1. Navigate to UniHealth directory:
   cd ~/Documents/GitHub/HEALTHCARE_SYSTEM/unihealth-360

2. Start the backend:
   docker compose up -d

3. Install and start Provider app (in new terminal):
   cd unihealth-provider
   npm install
   npx expo start

4. Install and start Patient app (in another terminal):
   cd unihealth-patient360
   npm install
   npx expo start

5. Test on Android emulator:
   Press 'a' in the Expo dev server

6. Build for Play Store:
   cd unihealth-provider
   eas build --platform android --profile production

================================================================================
TROUBLESHOOTING
================================================================================

Script says "not a git repository":
→ Make sure you're pointing to a valid GitHub clone folder
→ Should have a .git/ folder inside

Script fails to copy:
→ Try Option 2 (manual copy) or use IDE file explorer to drag-and-drop

Permission denied on script:
macOS/Linux: chmod +x add-unihealth-to-repo.sh

Want to see what will be added before committing:
→ After "Files staged", run: git diff --cached --name-status

Want to abort before pushing:
→ After staging but before push: git reset HEAD unihealth-360/
