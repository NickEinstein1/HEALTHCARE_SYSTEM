TROUBLESHOOTING (99% of Issues Covered)
================================================================================

Issue: "npm: command not found"
Fix:   Install Node.js from https://nodejs.org

Issue: Port 8081 in use
Fix:   Kill: lsof -ti:8081 | xargs kill -9 (macOS/Linux)

Issue: No emulator showing
Fix:   Open Android Studio → AVD Manager → Launch emulator

Issue: App crashes on startup
Fix:   npm install --legacy-peer-deps

Issue: Can't connect to device
Fix:   Enable USB debugging on phone
       Or: Use Expo Go app instead

Issue: Debugger port blocked
Fix:   Check firewall settings

99% of issues: Restart everything
  • Stop VS Code debugger (Shift+F5)
  • Close emulator
  • Kill Metro: lsof -ti:8081 | xargs kill -9
  • Close terminals
  • Reopen VS Code
  • Try again
