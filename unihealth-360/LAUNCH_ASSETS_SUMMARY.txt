────────────────────────────────────────────────────────────────────────────

NEXT STEP #2: INITIALIZE EAS (1-2 hours)
─────────────────────────────────────────

Follow: EAS_INITIALIZATION_GUIDE.md

Prerequisites:
  • npm installed (comes with Node.js)
  • GitHub account
  • EAS account (free at https://expo.dev)

Tasks:
  1. Create Expo account at https://expo.dev
  2. Open terminal in unihealth-provider/
  3. Run: eas init
  4. Follow prompts (project linking to GitHub)
  5. Run: eas credentials (configure signing)
  6. Repeat for unihealth-patient360/

What happens:
  • eas.json is updated with real project IDs (not REPLACE_WITH_...)
  • Signing credentials created and stored securely
  • Both apps ready for building

Verification:
  • eas.json files show real project IDs
  • Build test: eas build --platform android --profile development
  • Should complete in 5-10 minutes

After completing:
  git add unihealth-360/unihealth-*/eas.json
  git commit -m "feat: Initialize EAS projects with real IDs and credentials"
  git push origin main

────────────────────────────────────────────────────────────────────────────

NEXT STEP #3: VERIFY BUILDS WORK (15 minutes)
───────────────────────────────────────────────

After EAS is initialized:

  cd unihealth-provider
  eas build --platform android --profile development
  
  → Wait for build (3-5 minutes)
  → Should show "Build finished"
  → Download APK link (optional)

If successful:
  ✓ Assets are correct
  ✓ Firebase config is correct
  ✓ EAS credentials work
  ✓ Ready for Play Store submission

If failed:
  • Check error message in terminal
  • Verify google-services.json exists
  • Verify eas.json has real project ID
  • Check asset files are in place
