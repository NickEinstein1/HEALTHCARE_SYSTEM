SECURITY & AUTHENTICATION
================================================================================

✅ Keycloak OIDC
   └─ Shared realm (unihealth) with web portal
   └─ Bearer token auth on all API calls
   └─ Role-based access control (Zustand + backend enforcement)

✅ Biometric Auth
   └─ Face ID / Fingerprint (via expo-local-authentication)
   └─ Falls back to PIN if unavailable

✅ Encryption
   └─ TLS 1.3 in transit
   └─ AES-256 at rest (Expo SecureStore)
   └─ Field-level for PII (National ID, bank details, biometric refs)

✅ Token Management
   └─ Secure storage in native keychain (iOS) / keystore (Android)
   └─ Auto-refresh & expiry handling via Zustand
